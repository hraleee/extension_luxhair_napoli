# extension_luxhair_napoli

Sito web per Extension Luxhair Napoli: extension capelli, allungamento, infoltimento e corsi professionali.

## Getting Started

Prima di tutto, installa le dipendenze:

```bash
npm install
```

Avvia il server di sviluppo:

```bash
npm run dev
```

Apri [http://localhost:3000](http://localhost:3000) con il tuo browser per vedere il risultato.

## Scripts

- `npm run dev` — server di sviluppo
- `npm run build` — build di produzione
- `npm run start` — avvia la build di produzione
- `npm run lint` — controllo lint

## Struttura

- `components/` — componenti (Header, Hero, Servizi, Corsi, Galleria, Contatti, ecc.)
- `app/` — layout e pagina principale
- `public/images/` — immagini del sito (placeholder sostituibili con le foto reali)
